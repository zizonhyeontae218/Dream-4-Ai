# Dream-4-AI: 스탈린 정렬로 언어 재구성하기

> 텍스트 생성기가 아닙니다.  
> 언어 해체 장치입니다.  
> 의미를 넣으면 꿈의 잔해가 돌아옵니다.

**라이브 데모:** [zizonhyeontae218.github.io/Dream-4-Ai/dream4ai.html](https://zizonhyeontae218.github.io/Dream-4-Ai/dream4ai.html)

---

## 이것은 무엇인가요?

**Dream-4-AI**는 **파괴적 드림 알고리즘(Destructive Dream Algorithm)**을 기반으로 한 텍스트 파괴 엔진입니다.

대부분의 AI는 의미를 보존하려 합니다.  
이 프로젝트는 반대로 움직입니다.

문장을 분해하고, 구조를 으깨고, 대부분의 조각을 버린 뒤, 살아남은 조각만으로 모델이 무언가를 다시 만들도록 강제합니다. 목표는 정확성이 아니라 창발성입니다.

복구가 아닙니다.  
의역도 아닙니다.  
“더 나은 글쓰기”도 아닙니다.

**통제된 파괴.**

---

## 왜 만들었나요?

현대 LLM은 일관성에 지나치게 집착합니다. 유용하지만, 그만큼 출력은 무균적으로 변합니다. 한때 환각은 낯설고 우연한 아름다움의 원천이었습니다. 이제 모델은 선로를 벗어나지 않도록 학습됩니다.

이 프로젝트는 의도적으로 그 선로를 이탈시키기 위해 존재합니다.

Dream-4-AI는 깨끗한 의도에서 텍스트를 생성하라고 모델에 요청하는 대신, 체계적으로 파괴된 문장의 잔해를 입력합니다. 그 결과물은 손실, 압축, 기묘한 생존 편향에 의해 형성됩니다.

다시 말해,

> 먼저 문장을 죽이고,  
> 그다음에도 무엇이 살고 싶어 하는지 봅니다.

---

## 핵심 아이디어

이 알고리즘은 텍스트를 깊이 이해하려 하지 않습니다.  
대신 조금 더 무례한 일을 합니다.

1. 입력을 조각으로 나눕니다.
2. 최소한의 골격으로 순서를 바꿉니다.
3. 각 조각에 점수를 부여합니다.
4. **스탈린 정렬(Stalin Sort)**로 대부분을 제거합니다.
5. 생존한 조각만으로 재구성하게 합니다.

최종 결과물은 보통 원문이 손상된 버전이 아닙니다.  
선택적 붕괴에서 태어난 새로운 객체입니다.

---

## 작동 방식

### 단계 1 — 정규화

입력 텍스트를 소문자로 바꾸고, 문장부호를 제거한 뒤, 문장을 단어 단위로 토큰화합니다.

### 단계 2 — 품사 태깅과 명사구 묶기

각 토큰을 문법적 역할에 따라 분류합니다.  
`his cat`, `sally and my brother` 같은 명사구는 하나의 덩어리로 합쳐 원자 단위처럼 다룹니다.

### 단계 3 — 재배열

토큰을 거친 문법 골격으로 재배열합니다.

```text
VERB → NOUN_CHUNK → OTHER
```

이 과정은 잔해를 일관되게 파괴할 수 있을 만큼의 최소 구조만 남깁니다.

### 단계 4 — 점수 계산

각 토큰에는 다음 점수가 부여됩니다.

```text
value(token) = 모든 문자의 알파벳 값 합계 (a=1, b=2, ... z=26)
score(token) = value(token) + position_index
```

아주 작은 위치 편향을 더해, 순서 역시 흔적으로 남도록 합니다.

### 단계 5 — 스탈린 정렬

여기가 주요 집행 단계입니다.

단조 비감소 필터를 적용합니다.

- 첫 번째 토큰은 생존합니다.
- 다음 토큰은 점수가 직전 생존 토큰보다 크거나 같을 때만 생존합니다.
- 나머지는 모두 제거됩니다.

긴 입력에서는 보통 재료의 90~95%가 사라집니다.

### 단계 6 — 재구성

남은 조각은 엄격한 제약과 함께 Gemini 2.5 Flash에 전달됩니다.

- 살아남은 단어만 사용합니다.
- 아주 적은 수의 연결어만 허용합니다.  
  (`it`, `he`, `she`, `they`, `is`, `are`, `was`, `were`, `do`, `does`, `did`, `have`, `has`, `had`, `and`, `or`, `not`)

모델에는 원래 의미를 복원하라고 지시하지 않습니다.  
대신 잔해로 무언가를 만들라고 지시합니다.

바로 그 “무언가”가 핵심입니다.

## 기능

- 모든 파괴 단계를 단계별로 시각화
- 색상으로 구분하는 품사 태깅(동사 / 명사구 / 기타)
- 토큰별 점수를 보여 주는 실시간 스탈린 정렬
- 선택적 노이즈 가중치(토큰마다 ±15의 무작위 오프셋)
- 타자기 스타일 출력
- 신경망 재구성을 위한 Gemini API 연동

---

## 설정

1. aistudio.google.com에서 무료 Gemini API 키를 발급받습니다.
2. 라이브 데모를 엽니다.
3. AUTH 패널에 API 키를 입력합니다.
4. 영어 텍스트를 붙여 넣고 실행합니다.

API 키는 저장되지 않습니다.  
키는 `generativelanguage.googleapis.com`으로 직접 전송됩니다.

## 예시

입력

```text
Among all the people I’ve talked with for a while, you have a pretty distinctive way of thinking.
```

스탈린 정렬 후 생존 조각

```text
ill, straight, pretty, distinctive
```

재구성 결과

```text
They are ill — straight, pretty, distinctive.
```

원래 문장은 사라졌습니다.  
좋습니다.

## 설계 메모

- 재구성 모델이 생존 단어를 더 누락하는 경우가 있습니다. 이는 의도된 두 번째 제거 과정으로 받아들입니다.
- 선택적 노이즈 가중치는 토큰 점수에 불안정성을 더하므로, 같은 입력도 실행마다 다르게 붕괴할 수 있습니다.
- 이 프로젝트는 정보 손실을 결함이 아니라 생성 메커니즘으로 다룹니다.
- 노이즈를 넣거나 잔해를 신경망 모델에 넘기기 전까지 알고리즘은 결정론적입니다. 그 이후부터는 꿈꾸기 시작합니다.
